5. AI Code & Static Analysis

Key concepts and techniques

🎯 Chapter 5 Core Mission: Static Code Analysis, Inspections & AI Defect Patterns

Static testing evaluates code, architecture, and requirements without executing the software. Learn how to catch defects early via Fagan Inspections, linters (Pylint, Ruff), type checkers (MyPy), and recognize AI-generated code antipatterns.

1. Static Analysis vs. Dynamic Testing & Inspections

While dynamic testing discovers runtime failures by running test cases, static analysis discovers defects directly in the code or document before execution begins.

🔍 Formal Code Inspections (Fagan)

A structured, human review process following strict roles (Author, Inspector, Moderator, Scribe).
Key Advantage: Catches omitted requirements, unmaintainable architecture, and logical flaws that pass 100% automated branch coverage!

⚡ Automated Static Analysis Tools

Linters and abstract syntax tree (AST) scanners that automatically analyze source files.
Tool Suite:
• Pylint / Ruff: Syntax, code quality, unused variables, antipatterns.
• MyPy: Static type mismatches and None-pointer exceptions.
• Bandit / SonarQube: Hardcoded credentials & security vulnerabilities.

2. The Strict Exam Grading Rubric: Defect → Reason → Tool

On the exam, the professor requires you to analyze a Python code snippet and report defects using the 3-part formula:

Identified Defect Why It Is A Quality Problem (Reason) Likely Detection Tool
Mutable Default Argument (e.g., logger=[]) In Python, default lists are created once at function definition time. State persists across subsequent function calls, causing insidious data leakage and test pollution! Linter (Pylint / Ruff)
Unused Variable (e.g., message = "done") Dead store. Indicates dead code, unfinished development logic, or potential typo in a variable reference. Linter (Pylint / Ruff / Flake8)
Dead Code / Unreachable Branch Code that can never execute under any possible condition (e.g., if amount < 0 and amount > 100). Wastes maintenance effort and confuses reviewers. Static Analyzer / Code Review
Missing Type Annotation / None Dereference Passing None to a function that expects an object causes unhandled AttributeError crashes at runtime. Type Checker (MyPy)
