13. Mock Exam A

Key concepts and techniques

Mock Exam A - Questions

Suggested work time: 60 minutes. Do not look at the answers until you finish. Write short, precise, justified answers. Total: 40 marks.

✏️ Q1 - EC and BVA (6 marks)

A transfer amount must be an integer from 1 to 50000 inclusive. Define equivalence classes and list strong boundary values with expected results.

✏️ Q2 - Multi-dimensional isolation (4 marks)

A test suite contains (amount=0, session_valid=False) and (amount=60000, session_valid=False). Explain the structural problem and add two better tests.

✏️ Q3 - Pairwise (5 marks)

Parameters: browser Chrome/Firefox; role customer/admin; language EN/DE/FR. State the pairwise minimum and identify a suitable table.

✏️ Q4 - Decision table (5 marks)

Login succeeds when user exists, password is correct, and account is not locked. If locked, return LOCKED regardless of credentials. Build a compact decision table.

✏️ Q5 - Coverage and MC/DC (5 marks)

Decision: if session_valid and (amount_valid or manager_override): approve. Construct a minimum MC/DC suite.

✏️ Q6 - Static analysis (4 marks)

Find two issues: def add_event(event, events=[]): events.append(event); note="stored"; return len(events). Name likely tools.

✏️ Q7 - Gherkin (4 marks)

Repair: Scenario: Payment works / Given user has data / When user submits / Then it is correct. Rule: amount above 50000 must be rejected.

✏️ Q8 - Risk and test level (4 marks)

You can run only two tests: UI label spelling, transfer after expired session, report colour, transfer above limit. Choose two and justify.

✏️ Q9 - Performance (3 marks)

Classify: 200 expected users for one hour; 50 to 1000 users in one minute; account with 100000 records.

✏️ Q10 - Security (4 marks)

A user logs in correctly but reads another user’s balance. Classify the security area and propose evidence at two test levels.
