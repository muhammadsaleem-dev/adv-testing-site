🏛️ Official Q ARTIFACT A: WEAK TEST STRATEGY EXCERPT

Source: CH12_Block_G_Course_Summary.pdf

You review the following test strategy draft:

We will test FinCon thoroughly. The main scope is all important features. Testing will start when the software is ready. Testing ends when all tests are completed. Automation should be used where possible. Security will be checked by a tool.

Perform the following tasks:

  • (a) Identify five weaknesses in the excerpt.
  • (b) Rewrite two sentences into testable, reviewable statements.
👁️ Model Answer & Rubric Click to reveal Suggested Answer

Suggested Answer:

Weakness Statement Why it matters
"thoroughly" Not measurable. Needs specific coverage targets (e.g., 90% statement).
"all important features" Unclear scope. Features must be explicitly listed or referenced.
"software is ready" Vague entry criterion. What defines "ready"?
"all tests are completed" Weak exit criterion. Ignores defect severity and residual risk.
"security checked by a tool" Misleading. Automated tools cannot replace human security assessment/threat modeling.

Rewrites:

  • "Testing ends when 100% of P1 test cases have passed and zero Critical defects remain open."
  • "Testing begins when the CI/CD pipeline reports a successful build and all unit tests pass."

Requirement Risk Test Case
R1: PIN is exactly 4 digits Invalid login accepted TC-01: valid login
R2: amount is 1–100000 cents Invalid amount accepted TC-02: amount 500
R3: session must be valid Expired session accepted [Blank]

Perform the following tasks:

  • (a) Identify two gaps in the traceability matrix.
  • (b) Propose one additional test case for R3.
👁️ Model Answer & Rubric Click to reveal Suggested Answer

Suggested Answer:

  • Gap 1: R1 only has a valid login test; negative invalid PIN classes (e.g., 3 digits) are missing.
  • Gap 2: R2 only tests a valid representative value; boundary testing and invalid exterior values are missing.
  • Gap 3: R3 has no linked test case at all.
