16. Final Checklist

Key concepts and techniques

Final Night and Exam-Morning Checklist

Stop learning new material. Check that you can produce the following without notes.

  • Build valid and invalid equivalence classes
  • List six strong BVA values for a closed range
  • Explain why invalid inputs need valid complements
  • Find pairwise lower bound and a missing pair
  • Build a small decision table with priority
  • Differentiate statement, branch, condition and MC/DC
  • Construct MC/DC for three conditions
  • Explain mocks and verify not-called side effects
  • Classify mutable default, unused variable and unreachable code
  • List GTP phases and MTS sections
  • Create risk exposure and select response
  • Link requirement -> risk -> condition -> test
  • Repair vague Gherkin
  • Choose unit/API/UI automation level
  • Classify load/stress/spike/endurance/volume
  • Differentiate authentication and authorization
  • Explain scanner vs pen test vs review
  • Explain prompt injection with an observable oracle
During the exam: Read the verb: identify, construct, justify, compare or critique. Answer exactly that. Use tables for classes, boundaries, pairs, decisions and risks. Always include expected results and one sentence explaining why the case matters.

Final reminder: The strongest answers are not the longest. They are concrete, checkable, specification-based and connected to a defect or risk.
