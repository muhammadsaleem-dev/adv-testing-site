🏛️ Official Q GHERKIN TO AUTOMATION MAPPING

Source: CH08_Block_E_BDD_Part2.pdf

You are implementing step definitions for the following Gherkin scenario:

Given user has balance Given target does not exist When transfer is submitted Then rejected Then no money debited

Perform the following task:

  • (a) For each step, explain what technical check or setup is needed in the underlying test code.

Suggested Answer:

Gherkin Step Technical Check / Automation Setup
Given user has balance Database INSERT or API call to provision a test user account and mock a positive balance in the ledger.
Given target does not exist Database query to ensure the target IBAN is not in the system, or generate a guaranteed-invalid IBAN.
When transfer is submitted Execute the system under test (SUT) by sending an HTTP POST request to the transfer endpoint with the payload.
Then rejected Assert that the HTTP response code is 4xx (e.g., 400 Bad Request or 404 Not Found) and check the error JSON.
Then no money debited Database SELECT query to assert that the source user's balance remains identical to the initial setup value.
