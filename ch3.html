3. Pairwise & Decision Tables

Key concepts and techniques

🎯 Chapter 3 Core Mission: Mastering Combinatorial Testing & Logic Tables

When an application has multiple configuration parameters, testing every combination leads to combinatorial explosion (e.g., 2 × 2 × 3 = 12 tests, but 10 parameters with 4 values each = 410 = 1,048,576 tests). Pairwise (All-Pairs) Testing and Decision Tables drastically reduce tests while catching over 85% of multi-variable defects.

1. Pairwise (All-Pairs) Testing & The Minimum Theorem

Empirical research by NIST shows that most software defects are triggered by single parameters (single-mode faults) or interactions between two parameters (double-mode faults). Faults triggered by 3 or more variables interacting simultaneously are exceptionally rare.

Pairwise Testing ensures that every possible pair of parameter values is tested in at least one test case.

📐 The Pairwise Lower Bound Formula (Exam Essential):

The theoretical absolute minimum number of test cases required for pairwise coverage is determined by the product of the number of values of the two largest parameters:

Pairwise Minimum ≥ |ValuesLargest Parameter 1| × |ValuesLargest Parameter 2|

FinCon Report Export Example:

  • Format: PDF, CSV (2 values)
  • Include Summary: Yes, No (2 values)
  • Language: EN, DE, FR (3 values)

Total exhaustive combinations: 2 × 2 × 3 = 12 test cases.
Pairwise Minimum: The two largest parameters are Language (3) and Format (2).
Minimum test suite size = 3 × 2 = 6 test cases.

2. Cause-Effect Graphing (CEG) & Decision Tables

When complex business logic involves combinations of boolean conditions and interdependent rules, Cause-Effect Graphing maps inputs (causes) to outputs (effects) using boolean logic gates:

Identity / NOT

Cause C1 directly enables Effect E1, or inverted via NOT C1 (¬C1).

AND (&)

Effect occurs only if all connected causes are TRUE.

OR (||)

Effect occurs if at least one connected cause is TRUE.

Constraints (E, I, O, R)

Exclusive ($E$), Inclusive ($I$), One-and-only-one ($O$), Requires ($R$).
