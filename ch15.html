15. Additional Slide Questions

Key concepts and techniques
These are additional practice questions extracted from the professor's slides, fully fleshed out and formatted for rigorous study.
🏛️ Official Q PAYMENT TEST COMPLETENESS (4 MARKS)

You are given a function specification for a payment gateway:

  • The valid range for a transaction is 1 to 100000.
  • A colleague writes exactly two test cases: amount = 500 and amount = 50000.

Perform the following tasks:

  • (a) Identify at least three categories of missing test values.
  • (b) Explain why relying only on interior values is insufficient.

Suggested Answer:

  • Missing Categories: Exact boundaries (1, 100000), just-outside invalid values (0, 100001), negative values, and non-integer/missing types.
  • Reason: Interior values cannot reveal off-by-one errors in boundary guards, nor can they prove that the system correctly rejects invalid inputs (negative testing).
🏛️ Official Q DOCTEST INVALID TRIANGLE (4 MARKS)

A student writes a Python doctest that asserts the input (0, 0, 0) correctly returns "equilateral" because all three sides are equal.

Perform the following task:

  • (a) Explain why this logic is wrong and how the code/doctest should be fixed.

Suggested Answer:

  • Mathematical Flaw: A geometric triangle requires positive side lengths and must satisfy the triangle inequality theorem. A (0, 0, 0) shape does not exist.
  • Resolution: The implementation must add guards to reject zero or negative values. The doctest should be updated to expect a ValueError (or similar exception) for zero, negative, and degenerate cases like (1, 2, 3).
🏛️ Official Q MTS ONE-HOUR DECISION (RISK ANSWER)

A critical production release is scheduled, but testing has fallen behind. Only one hour remains before release.

Perform the following task:

  • (a) Using Risk-Based Testing principles, what must the Test Manager do?

Suggested Answer:

  • Action: Direct the remaining time exclusively toward testing the highest exposure areas (e.g., transfer authorization, validation, and session controls).
  • Communication: The Test Manager must clearly explain the probability and economic impact of untested areas to stakeholders, providing evidence of what was tested and explicitly identifying what lower-risk features are being consciously deferred to production.
🏛️ Official Q WEAK PERFORMANCE REPORT (CONCEPT)

A junior tester submits the following performance testing report to the stakeholders:

"The system is mostly fast with many users."

Perform the following task:

  • (a) Critique the report and provide an example of a proper performance statement.

Suggested Answer:

  • Critique: The statement is entirely vague, subjective, and non-actionable. It lacks concrete load parameters and measurable response criteria.
  • Correction: A proper report must use quantifiable metrics and specific loads.
    Example: "The 95th percentile response time remains under 200ms when subjected to a load of 10,000 concurrent users."
