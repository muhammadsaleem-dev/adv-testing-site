Key concepts and techniques

🎯 Chapter 12 Core Mission: Course Synthesis & The 3 Prepared Exam Artifacts

This chapter brings together the entire curriculum for exam day. Master the analysis of the 3 Prepared Exam Artifacts (Weak Test Strategy, Incomplete Risk Table, Traceability Gap Analysis) and review the complete syllabus checklist.

1. The 3 Prepared Exam Summary Artifacts

Artifact A: Weak Test Strategy Excerpt

"We will test FinCon thoroughly. The main scope is all important features. Testing will start when the software is ready. Testing ends when all tests are completed. Automation should be used where possible. Security will be checked by a tool."

5 Fatal Flaws to Identify:
  • "thoroughly": Unmeasurable vanity claim.
  • "all important features": Undefined scope.
  • "software is ready": Vague, non-objective entry criterion.
  • "all tests completed": Weak exit criterion ignoring open defects and risk.
  • "security checked by a tool": Tools cannot replace threat modeling and architectural risk analysis.

Artifact B: Incomplete Risk Exposure Table

Calculate $\text{Exposure} = \text{Probability} \times \text{Impact}$ for all items. Assign boundary and security tests to highest exposure (e.g. Exposure 6), and lightweight visual reviews to lowest exposure (e.g. Exposure 2).

Artifact C: Traceability Gap Analysis

Find requirements missing negative test cases (e.g., valid PIN tested, but invalid length missing; amount 500 tested, but boundary 100,001 missing; expired session has no linked test case).
